# CS-320_Software-Test-Automation-and-Quality-Assurance
Software Test, Automation, and Quality Assurance

SNHU Course

This repository includes the Contact Service java files from Project One in it's respective branch as well as the Project Two summary and reflections report in it's own respective branch.

## How can I ensure that my code, program, or software is functional and secure?
I ensure that my software is functional and secure by writing comprehensive unit tests that validate both expected and unexpected behavior. During this course, I utilized JUnit to assess valid inputs, invalid inputs, and edge cases, including null values, duplicate IDs, incorrect field lengths, and invalid appointment dates. I also structured my classes to implement validation rules that prevent invalid data from entering the system. Integrating comprehensive testing with input validation enhances reliability and lowers the chances of defects being released into production..

## How do I interpret user needs and incorporate them into a program?
I interpret user needs by thoroughly examining the software specifications and converting each requirement into distinct features and test scenarios. In this project, I established validation rules directly derived from the provided specifications, including character limits, unique IDs, future appointment dates, and mandatory fields. I subsequently developed unit tests to ensure that all requirements were fulfilled and that invalid inputs were handled correctly. This method guarantees that the completed software operates according to user expectations while preserving data integrity.

## How do I approach designing software?
I approach software design by dividing a problem into smaller, manageable components, each with a distinct responsibility. In this project, I developed separate classes for contacts, tasks, appointments, and their respective service classes, which made the code easier to organize, test, and maintain. I also considered validation and testing throughout development rather than postponing them until the project was complete. Creating software with an emphasis on modularity, maintainability, and testing results in code that is easier to debug, extend, and refine over time.
